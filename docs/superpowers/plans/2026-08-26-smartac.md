# SmartThings AC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Omarchy bar widget that turns an air conditioner on and off and sets its temperature through the SmartThings cloud API.

**Architecture:** A `bash` backend (`bin/smartac`) owns every HTTP call and the keyring token; QML owns only rendering and a poll timer. The backend speaks JSON on stdout so the QML never parses prose, and runs as a short-lived child so a network failure cannot degrade the shell.

**Tech Stack:** bash, curl, jq, libsecret (`secret-tool`), QML (Quickshell), node (tests only).

**Spec:** `docs/superpowers/specs/2026-08-26-smartac-design.md`

## Global Constraints

- Plugin id: `arturhash.smartac`. Never the reserved `omarchy.*` namespace.
- `manifest.json` at the repository root, `schemaVersion: 1`.
- No symlinks anywhere inside the plugin folder — `omarchy plugin validate` rejects them.
- Entry point paths are relative and must exist.
- **The token is read from stdin, never from a command-line argument.** `/proc/<pid>/cmdline` is readable by every process running as the same user.
- The token never appears in a config file, in a log, or in `doctor` output beyond a redacted prefix.
- No systemd unit. Removal must be `rm -rf` of the plugin directory.
- Every backend command exits non-zero on failure and writes `{"error": "..."}` to stderr.
- API base: `https://api.smartthings.com/v1`. Auth header: `Authorization: Bearer <token>`.
- `Model.js` stays Qt-free so it runs under node.

### Base-component facts, verified against the installed shell

Do not assume otherwise; each of these was wrong in an earlier draft.

- `Ui/Panel` provides `bar`, `moduleName`, `settings`, `controller`, and a **readonly** `opened`. It does **not** provide `foreground` or `fontFamily` — a plugin derives those itself as `bar ? bar.foreground : Color.foreground`.
- Opening and closing belong to the **bar widget**, which drives `panel.controller.open`. The panel cannot open itself.
- `Ui/TextField` masks input with `password: true`. There is no `echoMode`.
- `Quickshell.Io.Process` supports `stdinEnabled: true` plus `write()` inside `onStarted` — the shell's own network panel uses exactly this for 802.1X secrets.

```bash
# Backend tests. Every external command the backend touches is faked on PATH,
# so nothing here reaches the network or the real keyring.
set -uo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
PASS=0; FAIL=0

setup() {
  TMP=$(mktemp -d)
  export SECRET_STORE="$TMP/secret"
  export PATH="$TMP/bin:$PATH"
  mkdir -p "$TMP/bin"
  cat >"$TMP/bin/secret-tool" <<'FAKE'
#!/usr/bin/env bash
case "$1" in
  store)  cat > "$SECRET_STORE" ;;
  lookup) [[ -f $SECRET_STORE ]] || exit 1; cat "$SECRET_STORE" ;;
  clear)  rm -f "$SECRET_STORE" ;;
esac
FAKE
  chmod +x "$TMP/bin/secret-tool"
}

teardown() { rm -rf "$TMP"; }

ok()    { PASS=$((PASS+1)); printf '  ok    %s\n' "$1"; }
bad()   { FAIL=$((FAIL+1)); printf '  FAIL  %s\n        %s\n' "$1" "$2"; }
check() { [[ $2 == "$3" ]] && ok "$1" || bad "$1" "expected [$3], got [$2]"; }

test_token_set_reads_stdin() {
  setup

  check "token set stores what came on stdin" "$(cat "$SECRET_STORE")" "tok-abc"
  teardown
}

test_token_never_in_argv() {
```

- [ ] **Step 3: Write the backend**

`bin/smartac`:

```bash
#!/usr/bin/env bash
# SmartThings AC backend. Owns every HTTP call and the keyring token; prints
# JSON on stdout and nothing else, so the QML never parses prose.
set -uo pipefail

API="https://api.smartthings.com/v1"
SECRET_SERVICE="smartac"

die()  { printf '{"error":%s}\n' "$(jq -Rn --arg m "$1" '$m')" >&2; exit "${2:-1}"; }
need() { command -v "$1" >/dev/null 2>&1 || die "required command not found: $1" 4; }
need jq

# ------------------------------------------------------------------- token --

read_token() {
  local t
  t=$(secret-tool lookup service "$SECRET_SERVICE" key token 2>/dev/null) || return 1
  [[ -n $t ]] || return 1
  printf '%s' "$t"
}

cmd_token() {
  case "${1:-}" in
    set)
      # stdin only. An argument would land in /proc/<pid>/cmdline, which every
      # process running as this user can read while the call is in flight.
      [[ $# -eq 1 ]] || die "pass the token on stdin, not as an argument" 2
      [[ -t 0 ]] && die "pass the token on stdin, not as an argument" 2
      need secret-tool
      secret-tool store --label="SmartThings AC token" \
        service "$SECRET_SERVICE" key token || die "could not write to the keyring" 5
      printf '{"ok":true}\n' ;;
    clear)
      need secret-tool
      secret-tool clear service "$SECRET_SERVICE" key token 2>/dev/null
      printf '{"ok":true}\n' ;;
    status)
      need secret-tool
      if read_token >/dev/null 2>&1; then printf '{"hasToken":true}\n'
      else printf '{"hasToken":false}\n'; fi ;;
    *) die "usage: smartac token set|clear|status" 2 ;;
  esac
}

case "${1:-}" in
  token) shift; cmd_token "$@" ;;
  *) die "usage: smartac token|devices|status|power|temp|doctor" 2 ;;
esac
```

```bash
# --------------------------------------------------------------------- api --

api() {
  need curl
  local method="$1" path="$2" body="${3:-}" token raw status out
  token=$(read_token) || die "no token stored" 2

  local args=(-sS -X "$method" -H "Authorization: Bearer $token"
              -H "Accept: application/json" -m 15 -w $'\n%{http_code}')
  [[ -n $body ]] && args+=(-H "Content-Type: application/json" -d "$body")

  raw=$(curl "${args[@]}" "$API$path") || die "network unreachable" 6
  status="${raw##*$'\n'}"
  out="${raw%$'\n'*}"

  case "$status" in
    2*)  printf '%s' "$out" ;;
    401) secret-tool clear service "$SECRET_SERVICE" key token 2>/dev/null
         die "the token was rejected; enter a new one" 3 ;;
    429) die "rate limited by SmartThings" 7 ;;
    *)   die "SmartThings returned HTTP $status" 8 ;;
  esac
}

# ----------------------------------------------------------------- devices --

cmd_devices() {
  # airConditionerMode, not switch: switch alone matches every lamp in the
  # account, and a picker full of lamps is worse than no picker.
  api GET /devices | jq '{
    devices: [ .items[]
      | select(any(.components[]?.capabilities[]?; .id == "airConditionerMode"))
      | { id: .deviceId, label: (.label // .name // .deviceId) } ]
  }'
}
```

```bash
# ------------------------------------------------------------------ status --

require_device() { [[ -n ${1:-} ]] || die "pass --device <id>" 2; }

cmd_status() {
  local device=""
  while (( $# )); do
    case "$1" in
      --device) device="${2:-}"; shift 2 ;;
      --json)   shift ;;
      *)        die "unknown argument: $1" 2 ;;
    esac
  done
  require_device "$device"

  # Two calls. /status answers with the last values it saw and says nothing
  # about reachability, so an unplugged AC returns yesterday's numbers and
  # looks healthy. /health is the only thing that tells the two apart.
  local health online
  health=$(api GET "/devices/$device/health") || exit 1
  online=$(jq -r 'if .state == "ONLINE" then "true" else "false" end' <<<"$health")

  api GET "/devices/$device/status" | jq --argjson online "$online" '
    .components.main as $m | {
      power:       ($m.switch.switch.value // "off"),
      temperature: ($m.temperatureMeasurement.temperature.value // null),
      setpoint:    ($m.thermostatCoolingSetpoint.coolingSetpoint.value // null),
      unit:        ($m.temperatureMeasurement.temperature.unit // "C"),
      online:      $online
    }'
}
```

```bash
  body=$(jq -cn --arg c "$capability" --arg k "$command" --argjson a "$args_json" \
    '{commands:[{component:"main", capability:$c, command:$k, arguments:$a}]}')
  api POST "/devices/$device/commands" "$body" >/dev/null
  printf '{"ok":true}\n'
}

device_flag() {
  local device=""
  while (( $# )); do
    case "$1" in
      --device) device="${2:-}"; shift 2 ;;
      *) shift ;;
    esac
  done
  printf '%s' "$device"
}

cmd_power() {
  local state="${1:-}"; shift || true
  [[ $state == on || $state == off ]] || die "usage: smartac power on|off --device <id>" 2
  local device; device=$(device_flag "$@"); require_device "$device"
  send_command "$device" switch "$state"
}

cmd_temp() {
  local value="${1:-}"; shift || true
  [[ $value =~ ^-?[0-9]+([.][0-9]+)?$ ]] || die "temperature must be a number" 2
  local device; device=$(device_flag "$@"); require_device "$device"
  # --argjson, not --arg: the API rejects a quoted number for this argument.
```

```bash
cmd_doctor() {
  local caps=0 device=""

    case "$1" in
      --capabilities) caps=1; shift ;;

          | .components[]?.capabilities[]?.id' | sort

  else
    printf '  FAIL  no token stored\n'; return 1
  fi

  local n
  n=$(cmd_devices | jq -r '.devices | length') || return 1
  printf '  ok    reachable, %s air conditioner(s) visible\n' "$n"
```

```javascript
// Parsing and formatting for the SmartThings AC widget.
//
// Qt-free on purpose, so tests/test_model.js runs it under node. Anything that
// needs Qt.locale() belongs in the QML, not here.

var MAX_INTERVAL_MS = 10 * 60 * 1000

function emptyState() {
  return { ok: false, power: "off", temperature: null, setpoint: null, unit: "C", online: false }
}

// The backend is a child process. A crash mid-write leaves half a line on
// stdout, so every read goes through a parse that cannot throw.
function parseStatus(text) {
  var raw = String(text || "").trim()
  if (raw === "") return emptyState()
  try {
    var d = JSON.parse(raw)
    if (!d || typeof d !== "object" || d.error) return emptyState()
    return {
      ok: true,
      power: d.power === "on" ? "on" : "off",
      temperature: (typeof d.temperature === "number") ? d.temperature : null,
      setpoint: (typeof d.setpoint === "number") ? d.setpoint : null,
      unit: d.unit || "C",
      online: d.online !== false
    }
  } catch (e) {
    return emptyState()
  }
}

// The bar shows the room temperature, and only when there is one. An empty
// string is "nothing to say" — the icon still renders.
function barLabel(state) {
  if (!state || !state.ok) return ""
  if (state.power !== "on") return ""
  if (typeof state.temperature !== "number") return ""
  return Math.round(state.temperature) + "°"
}

function clampSetpoint(value, min, max) {
  var v = Number(value)
  if (!isFinite(v)) return min
  return Math.min(max, Math.max(min, v))
}

// A device that is off does not change temperature on its own, so polling it
// as often as a running one spends requests for nothing.
function nextInterval(state, baseMs, consecutiveFailures) {
  var base = Number(baseMs) || 90000
  var fails = Number(consecutiveFailures) || 0
  if (fails > 0) return Math.min(MAX_INTERVAL_MS, base * Math.pow(2, fails))
  if (state && state.ok && state.power !== "on") return base * 2
  return base
}

if (typeof module !== "undefined" && module.exports) {
  module.exports = { parseStatus, barLabel, clampSetpoint, nextInterval, emptyState, MAX_INTERVAL_MS }
}
```

```qml
// Bar entry: an icon, plus the room temperature while the AC is running.
//
// Owns the poll timer, the backoff, and opening the panel — the panel's own
// `opened` is readonly, and the panel is torn down as it closes, so neither
// the timer nor the failure count could live there.
Item {
  id: root

  required property QtObject bar
  property var settings: ({})
  readonly property string deviceId: String(settings.deviceId || "")
  readonly property string pluginDir: Qt.resolvedUrl(".").toString().replace("file://", "")

  // Ui/Panel supplies neither of these; every plugin derives them from the bar.
  readonly property color contentForeground: bar ? bar.foreground : Color.foreground
  readonly property string contentFontFamily: bar ? bar.fontFamily : Style.font.family

  property var state: Model.emptyState()
  property int consecutiveFailures: 0
  readonly property string label: Model.barLabel(root.state)
  readonly property bool stale: root.consecutiveFailures > 0

  function open()  { if (panelLoader.item) panelLoader.item.controller.open = true }
  function close() { if (panelLoader.item) panelLoader.item.controller.open = false }
  function togglePanel() {
    if (!panelLoader.item) return
    var willOpen = !panelLoader.item.controller.open
    panelLoader.item.controller.open = willOpen
    if (willOpen) panelLoader.item.refreshAll()
  }

  function refresh() {
    if (root.deviceId === "") { root.state = Model.emptyState(); return }
    if (reader.running) return
    reader.command = [root.pluginDir + "bin/smartac", "status", "--json", "--device", root.deviceId]
    reader.running = true
  }

  Process {
    id: reader
    stdout: StdioCollector { id: readOut; waitForEnd: true }
    onExited: {
      var next = Model.parseStatus(readOut.text)
      if (next.ok) {
        root.state = next
        root.consecutiveFailures = 0
      } else {
        // Keep the last known state rather than blanking the bar, but stop
        // claiming it is current. Staleness is shown, never hidden.
        root.consecutiveFailures = root.consecutiveFailures + 1
      }
      poll.interval = Model.nextInterval(root.state, 90000, root.consecutiveFailures)
    }
  }

  Timer {
    id: poll
    interval: 90000
    repeat: true
    running: root.deviceId !== ""
    triggeredOnStart: true
    onTriggered: root.refresh()
  }

  implicitWidth: button.implicitWidth
  implicitHeight: button.implicitHeight

  WidgetButton {
    id: button
    anchors.fill: parent
    bar: root.bar
    text: root.label
    labelVisible: root.label !== ""
    // Dimmed when off, unreachable, or never configured. To someone glancing
    // at the bar those mean one thing: it is not cooling.
    opacity: (root.state.ok && root.state.online && root.state.power === "on") ? 1.0 : 0.55
    onPressed: function(b) { if (b === Qt.LeftButton) root.togglePanel() }
  }

    onLoaded: {
      item.host = root
      item.bar = root.bar
      item.foreground = Qt.binding(function() { return root.contentForeground })
      item.fontFamily = Qt.binding(function() { return root.contentFontFamily })
    }
  }
```

````markdown
# SmartThings AC

Turn an air conditioner on and off and set its temperature from the Omarchy
bar. The bar shows the room temperature while the unit is running.

Built for a Samsung WindFree, but nothing in it is Samsung-specific: any air
conditioner SmartThings exposes works the same way.

## What it does not do

Mode (cool / dry / wind / auto / heat), fan speed, scheduling, and more than
one unit at a time. All are possible; none are here yet.

There is no local control. Newer Samsung units answer only through Samsung's
cloud — the local protocol older models spoke on port 2878 is gone — so this
plugin talks to SmartThings and needs the internet to do anything.

## Requirements

- Omarchy 4 (Quattro)
- `curl`, `jq`, and `secret-tool` with a running keyring daemon

## Install

```bash
omarchy plugin add https://github.com/artur-hash/omarchy-smartac.git --enable
```

## Setup

Click the icon in the bar. With no token stored, the panel is the setup screen:

1. Open [account.smartthings.com/tokens](https://account.smartthings.com/tokens)
2. Generate a new personal access token
3. Grant only the **Devices** scopes: list, read, execute
4. Paste it into the panel

Then pick your air conditioner from the list.

## About the token

A SmartThings personal access token grants control of **every device in your
account**, not only the one you pick here. Grant only the Devices scopes: this
plugin needs nothing else, and a token limited to those cannot reach your
account settings, your locations, or your other users.

The token is stored in your login keyring through `secret-tool`, never in a
configuration file. It is written to the backend on stdin rather than passed as
an argument, because an argument is visible in `/proc/<pid>/cmdline` to every
process running as you.

To remove it:

```bash
~/.config/omarchy/plugins/arturhash.smartac/bin/smartac token clear
```

Revoke it at [account.smartthings.com/tokens](https://account.smartthings.com/tokens).

## Diagnostics

```bash
bin/smartac doctor
bin/smartac doctor --capabilities --device <id>
```

The second prints the raw capability list your device reports, which is the
quickest way to find out why a control is missing.

## Removal

```bash
omarchy plugin remove arturhash.smartac
```

Nothing is left behind but the keyring entry, which `token clear` removes.
There is no systemd unit and no file outside the plugin directory.
````

## Notes for the executor

- **`omarchy restart shell` after every QML change.** A plugin hot-reload swaps the code but does not re-instantiate `Loader`-held items, so the old objects keep serving the UI and a correct fix looks broken.
- **Never put a real token in a test, a fixture, a commit, or a log.** The backend suite fakes both `secret-tool` and `curl`; nothing under `tests/` may reach the network.
- **Do not publish.** Submitting the marketplace listing is a separate decision, taken after the plugin has run against real hardware.
